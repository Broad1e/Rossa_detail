# Галерея работ

Раздел `#gallery` содержит три явно обозначенных демонстрационных снимка Porsche. Файлы хранятся локально в `public/images/gallery/`, авторы, источники и лицензии указаны в `src/data/gallery.ts` и в интерфейсе. При пустом массиве показываются нейтральные плейсхолдеры.

Карусель использует CSS perspective: активный кадр впереди, соседние сзади. Переключение — кнопками, стрелками клавиатуры, Home/End, свайпом, горизонтальным жестом трекпада или Shift + колесо. Обычная вертикальная прокрутка страницы сохраняется. При `prefers-reduced-motion` глубина и переходы отключены, виден только выбранный кадр. Автоматической прокрутки нет.

После получения фотографий:

1. Согласовать публикацию и отобрать снимки заказчицы.
2. Подготовить оптимизированные JPEG/WebP и поместить их в `public/images/works/`.
3. Заменить демонстрационные записи в `src/data/gallery.ts` реальными фотографиями (без `demo: true`):

```ts
export const galleryPhotos: GalleryPhoto[] = [
  {
    id: 'work-01',
    src: '/images/works/work-01.webp',
    alt: 'Точное описание того, что изображено на снимке',
    caption: 'Подпись, согласованная с заказчицей',
  },
];
```

Структуру компонентов менять не нужно. Кнопка фотографии открывает нативный модальный диалог: Tab остаётся внутри окна, Escape и кнопка «Закрыть» закрывают его, фокус возвращается к исходной фотографии. Прокрутка фона блокируется на время просмотра.

Если временно добавляются демонстрационные фото, у каждой записи необходимо указать `demo: true`: интерфейс явно обозначит их как демонстрацию, не работу студии. Видео не поддерживается и не добавлено.

Существующие внешние фото первого экрана и редакционного блока остаются визуальными референсами и не перенесены в галерею работ.

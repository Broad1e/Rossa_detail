# Фотографии для первой версии

Это визуальные референсы, а не портфолио ROSSA.DETAIL. На странице есть явная подпись. Фотографии подключены с оригинальных CDN Unsplash и Pexels; интернет требуется для загрузки фото. Проект и запуск остаются локальными.

1. Hero для компьютера: Nejc Soklič, горизонтальный снимок Porsche у гаража. https://unsplash.com/photos/a-black-sports-car-parked-in-front-of-a-garage-JUiftQpriyo
   Hero для телефона: Jonathan Ikemura, Porsche в тёмном гараже. https://unsplash.com/photos/a-black-car-parked-in-a-garage-s2unq_BAQjw
2. Детейлинг: Khunkorn Laowisit, полировка чёрного кузова. https://www.pexels.com/photo/a-person-polishing-the-black-car-5233259/
3. Деталь: sumith ks, тёмная фара Porsche. https://unsplash.com/photos/close-up-of-a-modern-car-headlight-on-black-matte-surface-2uOS_cpo1vA

Страницы источников обозначали фото как Free to use. Перед финальной публикацией заменить фотографиями студии и согласовать кадрирование.

Появление логотипа: 3.4 сек + задержка 0.25 сек (на узком экране 3.2 сек). Параллакс: смещение фона при прокрутке, максимум ±120 px, на узком экране ±65 px; сила увеличена до 0.30–0.34. При prefers-reduced-motion параллакс и появление отключены. Два фото выровнены в равные колонки с пропорцией 4:3. На первом экране используется cover с горизонтальным исходником Nejc Soklič и запасом для параллакса: фото заполняет всю ширину, боковые поля и маска удалены. На телефоне сохранён отдельный вертикальный снимок. Дополнительные зависимости не устанавливаются.



Обычный текст, подписи, меню, кнопки и описания — минимум 16 CSS px на компьютере и телефоне. Размеры заголовков и логотипов сохранены.

Мобильное обновление: для телефона используется тот же Porsche Nejc Soklič, что на ПК; полный силуэт помещается на затемнённом размытом фоне того же фото. Десктопные источник, кадрирование и стили сохранены. Мобильный параллакс: сила 1.15 от базовой, предел ±110 px, запас изображения 130 px. Обновление слушает прокрутку документа и visualViewport. При включённом уменьшении движения анимация отключается. Для локального просмотра служебные ресурсы Next.js разрешены на 127.0.0.1 и текущем Wi-Fi адресе 10.49.56.116; при смене адреса сети обновить allowedDevOrigins.

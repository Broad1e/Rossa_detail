# ROSSA.DETAIL

Локальный проект: Next.js (App Router), TypeScript, Tailwind CSS. Все исходники и зависимости находятся в этой папке. Облачный проект и публикация не настроены.

## Запуск в PowerShell

Откройте терминал в этой папке и выполните:

    npm.cmd run dev

Откройте http://127.0.0.1:3000. Для остановки нажмите Ctrl+C.

После переноса проекта на другой компьютер сначала выполните `npm.cmd ci`.

## Проверки

    npm.cmd run typecheck
    npm.cmd run lint
    npm.cmd run build

Главная страница: src/app/page.tsx. Стили: src/app/globals.css. Локальные шрифты: public/fonts.

## Первая версия

Тёмная адаптивная главная, логотип предоставленным шрифтом Porsche, подпись Hirro Sans, четыре раскрывающихся направления, блок подхода и ссылка на предоставленный профиль Instagram. Поддерживаются клавиатура и уменьшение движения.

Цены, адрес, телефон, сроки, фотографии работ и форма записи не добавлены: данных для них пока нет. Описания услуг и подхода — редакционный черновик для согласования, а не подтверждённые условия студии. Перед публикацией уточнить права на веб-использование предоставленных шрифтов.
